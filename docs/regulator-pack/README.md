# Regulator pack

> **What this directory is.** The documentation an examiner (FFIEC member-agency or external auditor) needs to use the chain in a real examination. None of the documents here are normative spec content; they are operational guides and templates that ship alongside the spec so the first examination does not require translating the design docs from scratch.

## Contents

- [`finding-language.md`](finding-language.md) — Standard examination-report language for verifier-detected findings
- [`CSF-2.0.md`](CSF-2.0.md) — NIST Cybersecurity Framework 2.0 mapping
- [`handbook-mapping.md`](handbook-mapping.md) — FFIEC IT Examination Handbook control-objective mapping
- [`deployment-package.md`](deployment-package.md) — Verifier hash, signature, and command-line reference for the regulator's IT shop
- [`sample-report.md`](sample-report.md) — Completed verifier report from a fictional tenant, for examiner training
- [`examiner-training.md`](examiner-training.md) — Onboarding a new examiner to chain verification
- [`examiner-approval-template.md`](examiner-approval-template.md) — Template for institution requests to relax seal cadence

The pack is versioned with the spec. `regulator-pack-v1.0` aligns with `chain-of-custody-v1.0`.
