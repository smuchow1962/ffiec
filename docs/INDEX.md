## Reading-order recommendations

### "I have 30 minutes; what should I read?"

If you're an examiner: `examiner-quickstart.md`. If you're a CEO: `management-summary.md`. If you're SOC: `control-map/TSC-mapping.md`.

### "I have 2 hours; what should I read?"

Read your audience-specific track above. Each track is sized for ~2 hours of reading.

### "I'm doing a deep dive."

Start with `design/00-overview.md`, work through the design docs in order, then your audience-specific deliverables.

## Document conventions

- All documents follow the project's writing voice (plainspoken, practical, grounded — see `CLAUDE.md` if curious)
- Cross-references use markdown links
- Spec content is in `spec/`; design rationale is in `docs/design/`; deliverable layer is in `docs/`
- Documents are versioned with the spec version

## Update cadence

This index is updated when new documents ship or when the audience-specific reading order changes materially.
